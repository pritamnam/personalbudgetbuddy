# My Budget Buddy

Create a responsive Personal Finance Tracker website with the following features:

Expense Tracking – allow users to add, edit, and delete daily expenses with categories (Food, Travel, Bills, etc.).

Budget Planning – enable users to set monthly budgets and show progress bars indicating usage.

Savings Goals – let users define savings targets and display motivational progress indicators.

Analytics Dashboard – visualize expenses and savings using interactive charts (pie chart, bar graph, trend line) with Chart.js.

Productivity Integration – include a simple reminder/to‑do list for financial tasks (e.g., bill payments).

The website should be built using HTML, CSS, and JavaScript (with Chart.js for visualization). Ensure clean, professional design, responsive layout
